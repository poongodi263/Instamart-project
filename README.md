# Instamart Project

An LLM-powered grocery shopping assistant project inspired by Instamart. The goal is to help users discover products and get useful shopping suggestions through natural-language interactions.

## Project status

Currently in the initial setup stage. The application features, technology stack, and setup instructions will be documented as development progresses.

## Planned features

- Ask grocery-related questions in natural language
- Find and explore grocery products
- Get relevant product suggestions
- Provide a simple, accessible user experience
